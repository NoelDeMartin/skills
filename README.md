# Noel De Martin's Skills

This repository includes LLM skills for my [Programming Patterns](https://noeldemartin.com/blog/programming-patterns).

If you're also curious to learn how I use AI in my workflow, check out [my AI Toolbox](https://github.com/noeldemartin/ai).

## Usage

Install the skills with the following command:

```sh
npx skills@latest add noeldemartin/skills
```

## The Skills

### Frontend

Skills for frontend development.

| Name                                                                                          | Description                                                       | Auto-invoked |
| --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------ |
| [Better Modals](https://noeldemartin.com/blog/the-problems-with-modals-and-how-to-solve-them) | Use imperative, promise-based modals instead of rendering inline. | Yes          |

### JavaScript

Skills for JavaScript or TypeScript projects.

| Name                                                                              | Description                                                                                                                                                            | Auto-invoked |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [Facades](https://noeldemartin.com/blog/programming-patterns-facades)             | Use the "Facade" pattern, which exposes global service instances through static-like accessors that can be swapped at runtime. | No           |
| [Magic Objects](https://noeldemartin.com/blog/programming-patterns-magic-objects) | Use the "Magic Object" pattern, which allows classes to seamlessly intercept access to undefined properties and methods (similar to PHP's magic methods).              | No           |
